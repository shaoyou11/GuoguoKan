# 果果看

原生 macOS 图片浏览器，Apple Silicon（M1 及后续），最低 macOS 27。

## 使用

在仓库 Releases 下载已编译的 ZIP 安装包。

建议将 Releases 中最新的 `GuoguoKan-版本号-arm64.zip` 解压到本机应用程序目录后运行。iCloud 会给直接同步的 app 添加 Finder 扩展属性，因此 ZIP 为校验交付件。支持拖入图片或文件夹、Finder 打开方式、单图和 1–6 列瀑布流、文件名搜索、EXIF、分享、置顶和原生全屏。

打开单张图片时加载同文件夹图片，打开文件夹仅扫描直接子文件，不递归。

↑ / ↓ 切换图片；← / → 切换同级文件夹（自然排序，跳过空目录，不循环）；⌘G 切换模式；⌘0 适应窗口；⌘1 实际像素；⌘+ / ⌘- 缩放；⌘R 旋转预览；⌘I 信息；⌘O 打开。触控板捏合缩放、拖动平移，双击切换适应与实际像素。

0.3.0 单图窗口按图片比例自动调整，受当前屏幕可用区域限制，不默认放大小图。检查器和导航栏计入窗口宽度；全屏不自动改窗口。可在“调整窗口”菜单关闭自动调整。顶部改为紧凑操作栏，窄窗口可横向滚动查看按钮，底边悬停显示文件信息。适应窗口时纵向滚轮切图、横向滚轮切同级文件夹，放大后滚动平移；按住 Shift 或 Command 滚动缩放。长按图片临时放大，松开恢复。概览单击选中、双击看图。

右键菜单含顶部图标快捷操作、检查器、文件操作、旋转和显示模式。⌘C 拷贝当前图片文件供 Finder 粘贴；⇧⌘C 拷贝到指定文件夹；⇧⌘M 移动到指定文件夹。两种目标文件夹操作均不覆盖同名文件，移动成功后从当前列表移除该图片。

## macOS 27

0.4.0 使用 SDK 27 的 `NSGlassEffectView` 玻璃控制栏、系统菜单、共享菜单和系统深浅色。单图顶部默认自动隐藏，移到顶边唤出，离开约 0.9 秒后收起，不挤压图片。齿轮按钮或 ⌘, 打开设置，可关闭自动隐藏、玻璃效果和切图淡入。切图保留旧图直到新图解码完成，再进行 0.18 秒淡入，跟随系统减少动态效果。图标改为简约黑白果实与取景框。

右键“拷贝到”和“移动”二级菜单共用最近 8 个目标文件夹，可添加常用目录。成功拷贝到文件夹后，单图和缩略图显示持久的“已拷贝”历史标记；⌘C 单独显示“已放入剪贴板”，不冒充已落盘。历史标记不保证目标文件一直存在。

显示模式包含单图、自适应网格、瀑布流、单列和横排。概览支持“仅收藏”筛选，收藏不移动原文件。“打开方式”列出系统注册的应用。“移到废纸篓”逐张确认，不永久删除。“自定义”允许添加可信 shell 脚本，每次运行需确认，以图片路径作为第一个参数交给 zsh，不拼接命令字符串；脚本具有当前用户的文件和网络权限。

## 构建

需要 Swift 6.2+、macOS 27 SDK。在本目录运行 `bash build.sh`，或用 Xcode 打开 Package.swift。中间产物保存在本机 Library/Caches，项目及交付包存于 iCloud。

## 当前边界

GitHub Actions 会在 main 推送、PR 和手动触发时测试并编译，安装包保留在运行记录的 Artifacts 中 30 天。更新 Info.plist 版本号后推送对应 v 版本标签（例如 v0.1.1），会自动创建 Release 并上传安装包及 SHA-256 校验文件。云端使用 xcode-27 托管环境，不依赖本地 Mac，无需签名密钥。

当前为预览版，使用 ad-hoc 签名，尚未完成 Developer ID 公证。已进行单图界面、原生右键菜单、切图、概览、拷贝和移动快捷键的本机 UI 检查；长按和触控板多指手势仍需实际使用验证。ImageIO 支持的格式可读取；GIF/WebP 等动画目前显示首帧。预览最长边限制为 8192 像素以控制内存，超过此尺寸的图片在 1:1 模式下会放大采样预览，不等于原始细节。缩略图只保存在内存，不写图片磁盘缓存。旋转不修改原文件。未实现递归目录、编辑导出或会话文件恢复。
