# 果果看

原生 macOS 图片浏览器，Apple Silicon（M1 及后续），最低 macOS 27。

## 使用

在仓库 Releases 下载已编译的 ZIP 安装包。

建议将 `交付/果果看-0.1.0-arm64.zip` 解压到本机应用程序目录后运行。iCloud 会给直接同步的 app 添加 Finder 扩展属性，因此 ZIP 为校验交付件。支持拖入图片或文件夹、Finder 打开方式、单图和 1–6 列瀑布流、文件名搜索、EXIF、分享、置顶和原生全屏。

打开单张图片时加载同文件夹图片，打开文件夹仅扫描直接子文件，不递归。

方向键切图；⌘G 切换模式；⌘0 适应窗口；⌘1 实际像素；⌘+ / ⌘- 缩放；⌘R 旋转预览；⌘I 信息；⌘O 打开。触控板捏合缩放、拖动平移，双击切换适应与实际像素。

## macOS 27

使用 SDK 27 的 `NSGlassEffectView.effectIsInteractive` 交互式玻璃控制栏，原生分段控件、工具栏、共享菜单、系统深浅色和窗口位置保存。手势识别器处理双击与拖动，系统负责键盘焦点循环。

## 构建

需要 Swift 6.2+、macOS 27 SDK。在本目录运行 `bash build.sh`，或用 Xcode 打开 Package.swift。中间产物保存在本机 Library/Caches，项目及交付包存于 iCloud。

## 当前边界

GitHub Actions 会在 main 推送、PR 和手动触发时测试并编译，安装包保留在运行记录的 Artifacts 中 30 天。更新 Info.plist 版本号后推送对应 v 版本标签（例如 v0.1.1），会自动创建 Release 并上传安装包及 SHA-256 校验文件。云端使用 xcode-27 托管环境，不依赖本地 Mac，无需签名密钥。

版本 0.1.0 为本地可运行首版，使用 ad-hoc 签名，尚未完成 Developer ID 公证或公开发行。ImageIO 支持的格式可读取；GIF/WebP 等动画目前显示首帧。预览最长边限制为 8192 像素以控制内存，超过此尺寸的图片在 1:1 模式下会放大采样预览，不等于原始细节。缩略图只保存在内存，不写图片磁盘缓存。旋转不修改原文件。未实现递归目录、编辑导出或会话文件恢复。
